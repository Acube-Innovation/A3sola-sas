New projects take these people, rules and days. A running project ({{ projects }} on {{ template_title | e }}) takes the new rules and SLA days, and its planned dates move, the next time it is saved. A task already started or assigned on it keeps its start date and people.

  • Starts when is the day a task's SLA days start counting. Its due date is that day plus the SLA days.
  • In order: one after another from the project start. First payment: all together the day any first payment is received. Or with the order if self-funded: the same, but a customer paying without a loan starts it with the order.
  • 50% payment: held until half the project value is received (an Operations Manager can exempt a project), then all start together. After another task: starts the day that task is completed, once 50% is in.
