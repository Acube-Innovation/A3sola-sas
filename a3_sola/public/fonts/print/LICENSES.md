# Fonts embedded in the proposal and quotation PDFs

Embedded in the print HTML (a3_sola.api.print_cover.print_fonts) so every server renders
the same text at the same size, whatever fonts it has installed.

- **Poppins** (Poppins-Regular.ttf, Poppins-Bold.ttf) - Indian Type Foundry,
  SIL Open Font License 1.1. Source: https://github.com/itfoundry/Poppins
- **P052** (P052-Roman.otf, P052-Bold.otf, P052-Italic.otf) - URW base35, a Palatino
  clone. Copyright 2015 URW Software; 2013, 2014 (URW)++ Design & Development.
  GNU AGPL v3 with this font exception:

  > As a special exception, permission is granted to include these font programs in a
  > Postscript or PDF file that consists of a document that contains text to be displayed
  > or printed using this font, regardless of the conditions or license applying to the
  > document itself.

  Source: https://github.com/ArtifexSoftware/urw-base35-fonts
